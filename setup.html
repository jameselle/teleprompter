Put the teleprompter on your iPhone

Phone and Mac need to be on the same Wi-Fi. Step 1 is only needed once.

Step 1 · once

Trust this Mac

  1. Installed a Teleprompter profile before? Remove it first: Settings → General → VPN & Device Management → Teleprompter → Remove Profile.
  2. Scan with the iPhone camera. It must open in Safari (Chrome can't install profiles). Tap Allow, then Close.
  3. Within 8 minutes: Settings → General → VPN & Device Management → Teleprompter → Install (top right), enter your passcode, Install again.
  4. Only after that: Settings → General → About → Certificate Trust Settings → turn on Teleprompter Local CA.

Step 2

Open the prompter

  1. Scan, open in Safari, allow camera and microphone.
  2. Share → Add to Home Screen so it opens full screen next time.

The profile trusts exactly one certificate: this Mac's. The key that made it was deleted, so it can't vouch for anything else. Remove it any time in Settings → General → VPN & Device Management.
